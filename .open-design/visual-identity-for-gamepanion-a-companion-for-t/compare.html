Visual identity for Gamepanion: a companion for the games you play. You tell Claude what happened while you play; Gamepanion files it and shows you only what you have found (spoiler-free). The web app is the human view into what was filed: games, playthroughs, quests, build, items, codex. Drop the old book/almanac/paper look completely. Modern game-app look; the user likes gamelog.gg (dark navy, near-white text, one bright accent, heavy tight sans headlines, small uppercase eyebrows, punchy voice) but Gamepanion must not be mistaken for it, so no electric blue. Dark first, light theme kept. Typeface: Atkinson Hyperlegible Next (accessibility), heavy weights for headlines. No game cover art: games show as generated tiles (initials on a colour derived from the name). Register tabs use the Okabe-Ito colours with their names, never meaning in colour alone. Each tile shows: palette with contrast, type specimen, a game tile row, a quest row with status, a button and a tab strip.
