# What it looks like

You talk to Claude while you play, the way you would to a friend on the sofa; Claude files it in your Gamepanion and gives it back when
you need it. An arrow is Claude using Gamepanion: into it when it files, back out when it reads. The globe is Claude searching the web
on the sites you keep as references: Gamepanion itself never does. The game here is invented.
