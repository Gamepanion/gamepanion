# So sieht es aus

Du redest mit Claude, während du spielst, so wie mit jemandem neben dir auf dem Sofa; Claude legt es in deinem Gamepanion ab und gibt es
dir zurück, wenn du es brauchst. Ein Pfeil ist Claude, das Gamepanion nutzt: hinein, wenn es ablegt, heraus, wenn es liest. Die Weltkugel
ist Claude, das im Web sucht, auf den Seiten, die du als Quellen hinterlegt hast: Gamepanion selbst tut das nie. Das Spiel hier ist
erfunden.
