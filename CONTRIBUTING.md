# Contributing

Every change starts from an issue; see `CLAUDE.md` for the commands and the checks a change must pass, and `docs/values.md` for what a change is judged against.

Gamepanion is licensed AGPL-3.0-only, and its maintainer runs a hosted instance that sells subscriptions, so the maintainer must be able to license every line. **A pull request from outside is merged only after its author accepts the [contributor licence agreement](CLA.md)** by commenting `I have read the CLA and I agree to it.` on the pull request. It is the standard Apache one, with the Maintainer as the party; you keep every right to your own work. Open an issue to discuss the change first.
